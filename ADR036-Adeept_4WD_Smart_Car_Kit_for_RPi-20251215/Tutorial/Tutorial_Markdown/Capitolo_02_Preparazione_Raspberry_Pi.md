# Capitolo 2: Preparazione del Raspberry Pi

Questo capitolo illustra la procedura di installazione del sistema operativo e la prima configurazione software.

## 📚 Lezioni Incluse
* **Lezione 3**: Guida all'avvio con Raspberry Pi (scrittura immagine Micro SD, configurazione iniziale).
* **Lezione 4**: Visualizzare e modificare il codice sorgente su Raspberry Pi.

## ⚙️ Concetti Chiave & Configurazione
* **Raspberry Pi OS**: Il sistema operativo basato su Debian installato sulla scheda Micro SD.
* **Accesso Remoto SSH**: Abilitazione della shell sicura per amministrare il robot da remoto senza monitor/tastiera collegati.
* **Editing del Codice**: Tecniche per visualizzare e modificare gli script Python direttamente sul robot (es. tramite terminale con `nano`, connessioni SFTP o estensioni SSH remote come VS Code Remote Development).
